# Suggested 6–8 minute demonstration

1. **0:00–0:45:** Explain Track D and the local study-companion workflow. Show
   account isolation and CPU/GPU configuration options.
2. **0:45–1:45:** Upload a short document/deck and show preparation progress,
   extracted source locations and the material becoming ready.
3. **1:45–3:00:** Ask a source-backed question, click its original-page citation,
   ask an off-material question, and show the separately labelled background.
4. **3:00–4:00:** Open a diagram, ask about visible arrows/axes, and compare the
   returned interpretation with the actual figure. Explain uncertainty.
5. **4:00–5:30:** Run a diagnostic and numerical practice. Show unit handling,
   wrong-answer cited feedback, a possible misconception and mastery updates.
6. **5:30–6:45:** Show the architecture and actual live evaluation files. Explain
   RAGAS metrics, failed/null scores and synthetic student simulation assumptions.
7. **6:45–7:30:** State limitations and demonstrate one recoverable error.

Use real observed outputs. Do not label controlled tests or synthetic gains as
human validation. Record the video, upload it to YouTube, and place its actual
URL in your submission. This script is not a completed demonstration video.
